# 研究记录中的清晰写作

**语言：** [English](human-writing-guide.md) | 简体中文

本指南把常见公式化写作模式的复核规则应用于 STAR 的回复和叙述性记录。
目标是写出清楚、自然的研究文字，而不是判断作者身份或规避检测器。
证据、状态、所有权与溯源仍以[研究工作流规范](research-workflow-conventions.zh-CN.md)为准。

## 1. 保持内容与出处不变

风格编辑可以重排、合并、拆分或缩短正文，但不得改变研究记录。

- 保留事实、数字、日期、阈值、引用、引文、归属、来源质量、状态、决定、未确定性、负面结果、开放事项和技术区别。
- 保留字面字段、标识符、名称、路径、命令、flag、环境键、代码、链接和完成判据。
- 分开已记录事实、有支持的推论和开放问题。
  同时分开来源主张与本项目判断、日志自报与分析发现、时间先后与因果关系。
- 信息缺失或记录冲突时，保留缺口并转给负责的工作流。
  不得补入看似合理的细节、来源、观点或结论。

统一使用一个判据：改写后，下一个读者能否还原同一项论断、状态、未确定性、决定和来源？

## 2. 贴合作者与记录

有经作者确认的样本时遵循样本。
匹配其中可观察的用词、句子推进、标点、过渡、限定方式和有意重复，但不得借用句子，也不得添加事实、观点、幽默或刻意的混乱。
没有样本时，使用克制、直接的技术表达。

- 先写答案、发现、改动或阻塞原因；结尾停在最后一个有用事实、决定、命令或开放事项上。
- 使用项目中的规范术语和简单动词。
  主体影响解释时，写清谁测量、推断、决定或实现了什么。
- 用具体证据替代意义宣告。
  写清发生了什么变化、对应哪个运行或条件，以及它为何改变决定。
- 保持产物职责清楚：想法与计划保留约束和停止判据；文献正文分开来源主张与本地综合；实验正文保留临时判断和不利结果；方法文档与发布文档只编译已核验来源，不用流畅文字修补缺口或推销预期影响。
- 只有产物类型和经作者确认的来源都需要时才增加个性。
  技术与参考正文保持中性。

## 3. 按模式组合复核

以下内容是编辑信号，不是禁用形式，也不能证明文本由 AI 生成。
多个信号集中出现、同一模板反复出现，或某个模式引入无依据论断时，才按段落改写。

| 复核对象 | 改写方向 |
| --- | --- |
| 夸大意义、宣传话术、罗列名望、无依据的最高级或套路化乐观结尾 | 确切结果及其有支持的影响。 |
| 模糊归因、知识限制声明或看似合理的猜测 | 明确且已核验的来源与可检查命题；否则显式保留缺口或删除。 |
| 空洞分析尾巴、抽象行动链、隐藏主体或限定语堆叠 | 直接的“事实—推论”关系、必要时明确主体，并只保留证据要求的限定。 |
| 反复使用“不仅……而且……”、强凑三项或虚假范围、虚设异议或备选方案、刻意坦诚、金句或假装揭示“深层本质” | 删除起草脚手架，只写真实关系、约束或选择。 |
| 套路化路标、重复标题、填充语、问候、赞美、道歉、预告、继续服务邀请或通用结尾 | 直接写内容，只保留读者需要的导航。 |
| 术语轮换、套话密集、重复句首、均匀节奏、戏剧化碎句、过多破折号、装饰性强调、标签堆叠的列表或表情符号 | 保持名称稳定；句法、节奏和格式只在有明确功能时变化。 |

不要孤立禁用某个词、连接词、被动句、第一人称、长句、列表或破折号。
一种形式表达真实关系、保留技术含义、符合作者习惯或展示必要结构时，应当保留。
引文、题名、代码、数据和字面字段即使命中观察模式，也不得仅为消除模式而改写

## 4. 改写并验证

1. 确定产物所有者、目标读者、规定语言和允许使用的来源。
2. 标出必须原样保留的字面内容和语义内容。
3. 梳理“事实—支撑—推论”顺序，并按段落判断模式组合。
4. 围绕实质内容整体改写，不逐个替换观察词。
5. 将修订版与来源对照。
   恢复遗漏的限定语、状态、引用、路径、命令和不利结果，并删除新增论断。
6. 运行负责该产物的工作流所要求的检查，并确认下一个读者能找到所需决定、开放事项、来源、文件或命令。

只有可追溯性、状态、未确定性、因果边界、术语和所有权均保持不变，修订才可交付。
