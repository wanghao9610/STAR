# Step 9: Synthesize related_work.md (synthesize mode only)

Compile the existing notes into `metds/refs/related_work.md` — the material a paper's Related Work section is written from. Offline: no fetching, no new reading. No notes under `metds/refs/` → say so and stop; the full pass or append mode builds them first.

1. Read the whole base: every note (`metds/refs/<ABBREV>.md`, its §5 Relation to This Project above all), `refs_index.md`, `reference.bib`'s category blocks, and the Step 0 method source (root plan §2/§3) for the positioning frame.
2. Organize by theme, following the bib's categories — merge or split only where the notes justify it. Per theme, one paragraph: what these works do and what they cannot do for this method, every claim drawn from that paper's own note, citekeys cited inline as `[@citekey]`. Within a theme, the impact scores in the index's §5 set order and length — high scorers first and fullest — and the closing positioning paragraph answers the top-scored core papers by name: those are the works a reviewer will raise. A low-scored or `new`-flagged paper is still cited wherever relevance demands it; the score allocates attention, never membership (Core Principle 4). Scores are read from the index as written — this mode fetches nothing. A note-backed paper's link form is `**[<ABBREV>](<ABBREV>.md)** [@citekey]`, the file name copied from the note on disk (`<ABBREV>.md`, carrying the `_<year>` suffix where Step 3 needed one), never rebuilt from the citekey; `related_work.md` sits in the notes' directory, so the bare file name is the whole path. Close with the positioning paragraph — what none of them do — grounded in the method source's §2.
3. Characterize a paper only from its own note, and no deeper than that note's `depth:` admits. Nothing comes from memory. A theme too thin to write becomes a gap naming the papers to read (`star-refs-reviewer <arxiv-id>` each, or one `add` for the list) — never padded prose.
4. Frontmatter: `type: related_work`, `language` (Step 0.4's rule), `generated:` (real date), `sources:` (the notes and index read, each with its date). On re-run, the overwrite rule in State & File Rules applies.
5. Digest ≤500 words: themes written, citekeys cited vs entries total, thin-note gaps with the read-next list, and the boundary: compiled material, every claim traced to a note and nothing written from memory — voice, ordering, and final citation style belong to the writing tool.
