# Agent 交办说明（Pi——本地履行）

EXEC_PLAN 里每个步骤(或每个连贯步骤组)派一次 `star_subagent`。要改文件的步骤用 `agent: "star-implementer"`,只读摸底用 `agent: "star-collector"`。主 agent 编排并复核,受派方只做这一个步骤的改动与运行——只管一小块,以便失败可定位、上下文短。

**在这个偏好之内,档位仍旧跟着步骤走。** 机械改写的步骤——填模板、挪文件、改计划已经点名的符号、跑格式化、设一个计划已写明的取值——要用的判断很少,若一次派发能挑用多少算力,就取便宜的一端:这一步自己的检查会兜住错误,而这里换档位只改账单、不改结果。写或改逻辑的步骤——计划只说要达成什么、没说要敲什么——用默认档位。两边都读得通的步骤算逻辑:便宜的 agent 在逻辑上出错,代价是一次重试加主 agent 的复核,比省下的档位更贵。

**连贯步骤组**指至多 3 个 EXEC_PLAN 动作:它们碰同一批文件、拆开就没有意义、共用同一个 check。除此之外都是各自独立的步骤。一个组只做一次、只检查一次,写进 EXEC_LOG 时每个成员动作各占一行并带上组标识——没做完的组,每一行都停在未完成,恢复时就不会把它读成已完成。碰到红线边界要把组拆开。

**步骤是串行的。** 绝不让两个步骤同时在手上:它们会争抢同一份 `EXEC_LOG.md`,而"只 stage 这一步碰过的文件"在两个写手同时在场时根本没有意义。`star-code-architect` 的并行规则是给相互独立的迁移组用的,有序的 plan 不是——别搬过来。

**这一步开工之前**,它名下的文件在 git 里是干净的。运行开始时就已经改动过的路径,单独点名为既有改动,并排除在下面所有恢复动作之外:它不归本次运行去回退。

## 交给 agent 什么

下面这些就是派发时写明、并由受派方在这一步全程照着守的条款:

- **范围**——该步目标,逐字取自 EXEC_PLAN,加上它绑定的 check。明确写:"**只**做这一步;不要推进到后续步骤。"
- **可写文件范围**——此外一律不碰:`${CODE_NAME}/` 下要新建或修改的确切文件/模块(取自缺口清单);`wkdrs/<run>/` 下的产物;`tasks/<plan-name>/` 下的中间文件,绝不碰别的计划的;以及仅限红线步骤的那份备用启动脚本 `execs/scpts/<run>.sh`——写它是轻的,跑它不是(`stop_line_rules_zh.md`)。匹配既有代码风格,只碰这一步需要的地方(AGENTS.md §3,精准克制的修改)。
- **运行环境**——Step 2 已经解析好的解释器绝对路径,逐字使用。不要每一步都回头读 `.env`:工作目录未必是项目根。缺包是它要返回的 blocker,绝不是它自己去装的东西(规约 §3.5)。
- **边界**——一个步骤**只能跑轻量验证**。落在红线上的步骤,**备好命令交回,不要跑**(`stop_line_rules_zh.md`)。

## agent 必须返回什么（记进日志）

- `changed`——新建/修改的文件,每个一行。
- `ran`——实际跑过的命令 + 结果,或 `none`。
- `check`——绑定 check 的结果:`pass` / `fail` + 证据(测试输出、指标、产物路径)。
- `blockers`——让它停下的东西,或 `none`。
- `handoff`——为用户备好的任何红线命令,或 `none`。

## agent 返回后

**把绑定的 check 作为一条独立命令跑一遍**,再记入 EXEC_LOG。代码写完了不等于这一步通过——check 的输出才是证据;而受托方自报的 pass,和任何一句声称一样,只是一句声称。

- **通过** → 在 EXEC_LOG 把该步标 `done`,附产物路径 + 检查结果;更新子计划 `exec_status` / `updated`。
- **失败** → 把失败记进 EXEC_LOG。重试之前先把这一步名下的文件恢复回去——已写明的既有改动除外。恢复到这一步开工时的样子,不是恢复到 `HEAD`:确认点可能拒绝了逐步提交,那时更早的已验证步骤同样没提交,重置到 `HEAD` 会把 EXEC_LOG 已经记为 `done` 的工作一并抹掉。恢复动作绝不越出这一步自己的文件;最多重试 2 次,把失败信息带进下一次尝试。仍失败 → 该步标 `blocked`:那些做了一半的改动,恢复之前先问(规约 §7.7——这是把关删除的),记下最终怎么处理的,无论哪种都把路径写清楚,带日志停下。没有哪一步可以留下无人认领的改动:后面某一步提交时 stage 的是"这一步碰过的文件",它分不出来。
- **有 handoff** → 把命令移到 EXEC_LOG"待用户执行"并停下;不要跑它。
