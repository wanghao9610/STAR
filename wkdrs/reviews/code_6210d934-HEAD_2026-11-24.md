- **F3** `.devin/hooks/star_involve_level.sh:5` (used by both Devin gates) — the level comes from `.env` alone. With `INVOLVE=low` in `.env`, a run the user starts with `involve=high` or `involve=medium` still has every in-project edit and every non-red-line shell call auto-approved.
  - **Rule:** conventions §7.7 (line 176): the invocation's token overrides `.env`. §13 (line 397) documents only the other direction (`low` under a higher `.env` keeps its prompts).
  - **Evidence:** the gate approves `{"tool_name":"edit","tool_input":{"file_path":"<root>/code/x.py"}}` under `.env` `INVOLVE=low`, and nothing in the payload can carry a higher token.
  - **Possible route:** Devin documents a `UserPromptSubmit` hook whose stdin carries `prompt` (`lifecycle-hooks.mdx:148-156`), and every payload carries `session_id`.
  - **Also affected, before this range:** the Codex and Qwen Code gates have the same `.env`-only direction.
  - **Fix:** record the last typed STAR command's `involve=` per `session_id` from a `UserPromptSubmit` hook into git-ignored state, and have the gates stay silent when it is `medium` or `high`. At minimum, document the unsafe direction in §13 and the gate headers.

A project that follows the note's own advice ("Update its hook commands to ../.agy/hooks/") gets no further note, yet keeps the old matcher and timeouts. `missing_hooks` checks file names only, so nothing else catches it either.
  - **What stays behind:** the pre-`054532d2` edit-gate matcher, which lacks `write_file|edit_file`, so agy CLI edits never reach the gate. The guard's timeout also stays at 10 s instead of 60.
  - **Rule:** the update contract (a kept config is never overwritten, but outdated STAR wiring is reported). This is the same drift class as the 2026-11-21 F1, fixed for Devin by `note_devin_hooks`.
  - **Evidence:** `git show 6210d934:.agents/hooks.json | sed 's#\.gemini/antigravity-cli/#.agy/#'` contains `../.agy/hooks/` four times, so the note stays silent. Its matcher is `write_to_file|replace_file_content|multi_replace_file_content`, where upstream's is `write_file|edit_file|write_to_file|…`, and it has four `"timeout": 10` where upstream's guard has 60. The effect fails closed (agy CLI edits keep prompting at `low`), but the update reports nothing.
  - **Fix:** compare each STAR script's matcher, timeout and command against upstream, as `note_devin_hooks` does, adapted to Antigravity's named-group schema. Name every command that still points at `../.gemini/antigravity-cli/`.
